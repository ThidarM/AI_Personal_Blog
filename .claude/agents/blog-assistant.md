# Blog Assistant

The `BlogAssistant` agent is the single AI persona for this project.

It supports the following blog-writing workflows:

- `generateArticle()` to create complete blog posts from a title and direction.
- `improveGrammar()` to refine text for clarity, grammar, and tone.
- `summarize()` to extract the main ideas into a concise summary.
- `generateTags()` to produce relevant blog tags from content.

This agent is the only one used for content generation and editorial tasks.
