# User Feedback — AI Personal Blog

- **How collected:** Online usability testing with 3 users.
- **When:** August 2026

## Raw feedback

1. The homepage is clean and easy to understand, but I would like to see more blog posts immediately without scrolling too much.
2. Signing in with Supabase works well, but the authentication pages could provide clearer success and error messages.
3. The application looks good on desktop, but the mobile layout and navigation could be improved.

## Themes (what keeps coming up)

- Users appreciate the clean design and simple navigation.
- Better content discovery (search, categories, filtering) would improve usability.
- Mobile responsiveness and authentication feedback should be improved.

## Top 3 things to fix

- [ ] Add blog search and category filtering.
- [ ] Improve the homepage hero section by highlighting AI-powered features more clearly.
- [ ] Improve responsive layout and user feedback messages for authentication.
