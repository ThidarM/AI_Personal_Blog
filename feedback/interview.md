# User Interview — AI Personal Blog

- **Who:** IT student (friend) who regularly reads technical blogs.
- **When:** August 2026
- **How:** In-person usability testing (approximately 15 minutes).

## What they do today (without your project)

The user regularly reads programming tutorials on Medium, Dev.to, and personal developer blogs. They bookmark useful articles to revisit later and prefer simple, distraction-free websites where the content is easy to scan and read.

## What they liked

The homepage felt clean and modern, and the interface was simple to navigate. Signing in with Supabase authentication was straightforward. Blog cards were easy to read, and the application loaded quickly on both desktop and mobile.

## What confused them / what's missing

There is no search function to find articles, and posts have no categories or tags, which makes it hard to discover related content. The homepage does not explain the AI-powered features clearly enough for a first-time visitor. On mobile, the spacing between sections could be improved for a more comfortable reading experience.

## What would make them actually use it

Blog search, categories, and tags would make content easier to discover. A rich text editor with image upload would make writing posts more flexible, and a better AI writing assistant would help with creating blog posts faster.

## What I'll change (next steps)

- [ ] Add blog search and category filtering.
- [ ] Improve the homepage hero section and mobile responsiveness.
