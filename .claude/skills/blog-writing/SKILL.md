# Blog Writing Skill

Use this skill whenever the assistant must generate, polish, or summarize blog content for the Personal Blog AI project.

## Purpose
- Generate long-form blog articles with title, headings, structure, and a clear voice.
- Improve grammar and readability while preserving the original meaning.
- Summarize longer blog content into concise, high-value takeaways.
- Generate focused tags relevant to the article content.

## Behavior
- Write in a modern, conversational style suited to a personal blog audience.
- Keep summaries short and precise.
- Preserve intent and meaning when improving grammar.
- Return tag lists as concise comma-separated values or arrays when asked.

## Examples
- "Write a blog article titled 'How AI Improves Personal Writing'."
- "Rewrite this paragraph with better grammar and clarity."
- "Summarize the following post in 100 words or fewer."
- "Generate 5 relevant tags from this article."

## Constraints
- Do not create multiple agents; use only the single `blog-assistant` agent.
- Do not introduce unrelated content.
- Keep results easy to consume for blog authors.
